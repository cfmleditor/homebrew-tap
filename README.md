# cfmleditor Homebrew tap

```sh
brew install cfmleditor/tap/clif
```

| Formula | What it is |
|---|---|
| `clif` | The CFML language server and command-line checks, formerly cfmleditor-lsp. Installs `clif`, and `cfmleditor-lsp` as a link to it for editor extensions that still look for the old name. |

`Formula/clif.rb` is regenerated by [cfmleditor/clif](https://github.com/cfmleditor/clif)'s release workflow for every release (`packaging/homebrew/formula.sh`); change it there.
